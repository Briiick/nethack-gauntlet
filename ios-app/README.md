# NetHack Gauntlet for iPhone and iPad

The phone version (`../mobile`) in a native shell, made with [Capacitor](https://capacitorjs.com).
The game, its art and the NetHack engine are bundled into the app, so it plays fully offline.
Inside the app it also gets a few native extras (`../mobile/js/native.js`):

- **Saves are real files** in the app's Documents folder. You can see them in the Files app
  (On My iPhone → NetHack), and iCloud backs them up.
- **Your Hall of Fame and saved-game details** are copied to `Documents/records.json`, so they
  survive iOS clearing web data.
- **Leaving the app saves the game.** iOS gives it a few extra seconds in the background to
  finish (`ios/App/App/SceneDelegate.swift`), and opening the app again carries on.
- **Haptics** when you long-press a square and when the game rings its bell.
- **Full screen:** no status bar, with the game's own icon and launch screen.

## Getting it onto TestFlight

### One-time setup

1. **Join the [Apple Developer Program](https://developer.apple.com/programs/)** ($99 a year).
2. **Create the app.** In [App Store Connect](https://appstoreconnect.apple.com), go to
   Apps → + → New App: platform iOS, name *NetHack Gauntlet* (or any free name), bundle ID
   `com.briiick.nethackgauntlet` (register it first under Certificates, IDs & Profiles → Identifiers
   if it isn't offered), any SKU.
3. **Make an API key.** Go to App Store Connect → Users and Access → Integrations → App Store Connect
   API → Team Keys → +, with **Admin** access (needed so the build can create its own signing
   certificate and profile). Download the `.p8` file (it can be downloaded only once), and note the
   Key ID and the Issuer ID shown above the list.
4. **Add four repository secrets** (GitHub → the repository → Settings → Secrets and variables →
   Actions → New repository secret):
   - `APPLE_TEAM_ID`: your team ID (Membership details on developer.apple.com)
   - `APP_STORE_CONNECT_KEY_ID`: the key's ID
   - `APP_STORE_CONNECT_ISSUER_ID`: the issuer ID
   - `APP_STORE_CONNECT_KEY`: the whole contents of the `.p8` file
5. **Testers.** In App Store Connect → the app → TestFlight → Internal Testing, add a group and put
   yourself in it. Internal testers (people on your App Store Connect team, up to 100) get each build
   with no review. External testers need a short beta review the first time.

### Each release

Bump `version` in `ios-app/package.json` when you want a new version number, then push a tag:

```sh
git tag ios-v0.1.0 && git push origin ios-v0.1.0
```

(or run *iPhone app (TestFlight)* by hand from the Actions tab). The workflow
(`.github/workflows/ios.yml`) does the rest on a GitHub Mac runner:
1. Builds the game into `ios-app/www`.
2. Copies it into the Xcode project.
3. Archives it, signed automatically with your API key.
4. Uploads it to App Store Connect, with the run number as the build number.

About 5–30 minutes later the build appears in TestFlight, and the TestFlight app on your phone
offers it. TestFlight builds expire after 90 days.

## Building on your Mac (optional)

You need Xcode 26 or newer.

```sh
cd ios-app
npm install
npm run build       # the game into www/, then copied into the Xcode project
npm run open        # opens Xcode: pick your team under Signing & Capabilities, then Run
```

Run `npm run build` again whenever the game changes. To try it in the Simulator, no Apple account is
needed: choose an iPhone simulator in Xcode and press Run.

## What's here

```
package.json            Capacitor and its plugins (app, filesystem, haptics)
capacitor.config.json   app ID, name, where the web files are (www/, built, not committed)
ExportOptions.plist     how the workflow signs and uploads the archive
ios/                    the Xcode project (generated by `npx cap add ios`, then edited:
                        App/Info.plist, App/SceneDelegate.swift, the icon and launch images)
```

## Before a public App Store release

TestFlight is a private beta. Before publishing on the App Store itself, check that NetHack's
licence (the NetHack General Public License) fits the App Store's terms. Its conditions on redistribution and source code have caused trouble for
other open-source games on the App Store. Other NetHack builds have shipped there, but read the
licence yourself or ask someone who knows.
